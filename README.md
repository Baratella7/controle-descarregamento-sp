# Controle de Descarregamento SP

Este projeto foi criado para resolver uma necessidade da empresa onde trabalho. Antes, a equipe conferia os volumes descarregados e montava o relatório manualmente. Agora, o sistema lê a planilha de descarga, compara os volumes previstos com os volumes registrados e gera o relatório.

A automação economiza cerca de **30 minutos por dia** na preparação do relatório.
